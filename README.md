# Hospital-Admissions-Dashboard
Hospital patient analytics dashboard | Power BI | Excel | Data Cleaning
An interactive hospital admissions dashboard built with Power BI (with an earlier Excel version), based on a cleaned healthcare admissions dataset.
Business Problem;

Hospital managers need a quick way to see who is being admitted, how long patients stay, and how many come back. This dashboard answers questions such as:

How many patients were admitted, and what is the male/female split?
Which wards and diagnoses have the most admissions?
What is the average length of stay (LOS) by age group?
What is the readmission rate, and how do outcomes compare?
How do admissions change over time?

Key fields: ward, diagnosis_code, age group, gender, los_days, readmission, outcome
Cleaning steps: [e.g. removed duplicates, fixed inconsistent text, handled missing values, corrected data types, created age groups]
Tools Used
Power BI (DAX measures, slicers, visuals)
Microsoft Excel(Data cleaning)

What's Inside the Dashboard
KPI cards: Number of Patients, Male Patients, Female Patients, Readmission Rate
Charts: admissions by ward, diagnosis, age group, outcome, and trend over time
Slicers: gender, ward, outcome, date
